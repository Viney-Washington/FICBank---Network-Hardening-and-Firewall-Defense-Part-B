## Project Overview
This project focused on identifying network-based threats and strengthening defenses through firewall configuration and traffic analysis. Security controls were implemented and tested to reduce exposure to common network attacks within the FIC Bank environment.

## Key Skills Demonstrated
- Firewall Rule Configuration (UFW)  
- Network Traffic Analysis (Wireshark)  
- Attack Identification and Mitigation  
- Packet Capture (PCAP) Analysis  
- Network Hardening Techniques  
- Security Control Validation  

## Tools & Technologies
- Wireshark  
- UFW Firewall  
- Linux Environment  

## Key Activities
- Configured UFW firewall rules to allow and block specific ports and services  
- Analyzed packet captures to observe TCP handshakes and network behavior  
- Verified blocked traffic using packet analysis (RST/ACK responses)  
- Identified insecure protocols and potential attack vectors within network traffic  
- Applied network hardening techniques to reduce attack surface  

## Outcome
Improved network security by implementing and validating firewall controls, confirming that unauthorized traffic was blocked, and strengthening visibility into network activity through packet analysis.
